# Second Live – World Genesis

Browserbasiertes Open-World-Spiel für Desktop, Smartphone und perspektivisch immersive VR. Die Spieler erschaffen die Welt durch reale Fotos, verändern sie durch Spielinteraktionen und reparieren dauerhaft beschädigte Objekte.

Dieses Repository dient als zentrale Versionsverwaltung des Projekts. Der vollständige Docker-Entwicklungsstand wird als separater Commit importiert. Keine echten Zugangsschlüssel, privaten Fotos oder Spielerdaten gehören in dieses öffentliche Repository.
