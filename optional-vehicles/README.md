# Premium vehicle pack

Upload the file `Second-Live-Premium-Vehicles.zip` to this directory without extracting or renaming it. The archive prepared for 0.15.25 contains five original GLBs and five distance-optimized GLBs, with CC BY 4.0 attribution.

The Docker build verifies every byte sequence against pinned SHA-256 digests and installs the models locally. No external download or browser request to the asset provider is required. Without this optional archive the previous vehicle models remain available. A present but corrupt archive fails the build, leaving the previous game version active.

Original assets: [Vinish.dev Realistic Cars](https://vinish.dev/free-3d-models/realistic-cars), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Modifications: distance-optimized meshes, in-game orientation/scale, colors, animation and taxi sign.
